# cherry internal help

Git 2.25 and 2.55 call parse_options with flags 0 before selecting the upstream and resolving commits. Internal help exits at its parser position. Malformed abbreviation values reached before help remain errors; values after help are not consumed. The abbreviation callback uses the existing decimal/ABI profile, including signed inputs and minimum clamping, rather than a nonnegative integer approximation.

First --help is documentation dispatch. Completion words are shortcuts only when sole parser words, unless earlier full help already exited. After --, tagged help-looking words remain operands, and option tuples are invalid API representation. Shape and NUL guards remain active even after help.

Finite comparisons retain each selected Git's exit code and repository-setup failures. Payload controls compare HEAD with itself in an isolated fixture and return before a revision walk; index, tracked file and HEAD-file bytes are checked unchanged after each call. They do not prove full patch-id, upstream configuration, ref/object, callback or platform grammar. All command audits remain partial.
