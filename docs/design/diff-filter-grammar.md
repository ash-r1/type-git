# Shared diff-filter callback letters

The inspected Git 2.25.1 and 2.55.0 sources build the same class vocabulary from `diff.c:diff_status_letters` and `diff.h`: `A C D M R T U X B` and `*`. The callback folds only ASCII lowercase letters for membership, so the corresponding lowercase letters are also valid. Empty strings, repetitions and mixed case are accepted. In particular, `bad` is a valid combination of lowercase classes. Other letters, digits, whitespace, separators and non-ASCII bytes are rejected.

The source callback binding applies to the complete shared command group and retained parser tables. Backfill retains both command-specific raw collectors and the existing nonempty-filter forbid rule; the shared binding does not replace that override. The validation group includes backfill as a control, with 26 direct callback scopes and 13 retained callback references. Validation consumes the full string and preserves raw argv and existing help phases. Earlier reached errors cannot be erased by later occurrences. The required string representation remains unchanged; booleans and missing values remain shape errors. NUL checks also remain separate.

This profile validates lexical acceptance only. Git 2.25 and 2.55 accumulate lowercase exclusion state differently, so no filter-state projection, payload matching or output selection is predicted. Literal validation rejects guaranteed forbidden ASCII before the existing finite dynamic/budget policy; symbolic and budget-exceeding inputs otherwise retain runtime validation. This is not a promise of complete symbolic-language analysis.

The baseline pilot contains 2,460 native/public help invocations across six selected Git versions and five representative commands, with 41 values and both help orders. They agree at runtime. Thirteen unused rejection assertions demonstrate missing literal constraints in the baseline, rather than an existing runtime compatibility bug. The pilot does not establish complete command or payload auditing; later checks must record their actual head and scope.
