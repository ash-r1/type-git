# Shared moved-color callback grammars

The mode callback calls `git_parse_maybe_bool` before exact case-sensitive names. It therefore accepts Git boolean words, signed 32-bit configuration integers and `plain`, `blocks`, `zebra`, `default`, `dimmed-zebra`, `dimmed_zebra`. The implementation reuses existing selected-native boolean/integer source profiles, including legacy bare units, INT_MIN and binary integer availability. Bare optional arguments and negation keep their native serialization; explicit boolean values remain invalid public optional-string shapes. Configuration-dependent bare-mode state and rendered colors remain native-owned.

The whitespace callback splits commas and trims only C ASCII whitespace. It records unknown-token errors without stopping. The exact token `no` resets all accumulated bits, including errors; indentation conflicts are tested after all tokens. Consequently `unknown,no`, `no,,no` and `é,no` can succeed while native Git prints earlier diagnostics. `no,unknown`, `no,` and a final combination of indentation with another whitespace class fail. Raw text is preserved so Git produces its own diagnostics. Negation bypasses whitespace parsing as in the native unset branch.

The type parser tracks ordinary, exclusive and invalid flags in token order. It does not reject a prefix before a later reset can clear it. Existing dynamic/128-step analysis limits remain conservative runtime checks, not complete symbolic or unbounded-language analysis. NUL, public shapes, help preemption and errors from earlier separate option occurrences remain independent checks.

The baseline pilot compares 3,036 native/public invocations across six Git versions: five representative help frontends with both help orders, plus no-change ordinary diff controls. They agree at runtime, including native diagnostic-producing recovery and version-specific integer boundaries. Seventeen unused rejection assertions establish missing literal constraints. These finite controls do not prove moved-line rendering, full command auditing or configuration/platform completeness.
