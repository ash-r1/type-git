# pack-redundant full usage

The canonical sole `[["--help-all"]]` call reaches the selected native Git before opt-in and pack filename constraints. Git 2.55.0 calls `show_usage_if_asked` before its handwritten option loop; Git 2.25.1 treats the spelling as an unknown option and prints usage instead. Native exit status and output streams remain unchanged. The existing short-help and first documentation-help paths are unchanged.

When the full-help tuple is reached by argument validation, its check requires exactly one command word. Existing earlier short-help and documentation exits keep their behavior. Tagged dash-leading operands still require the existing explicit separator representation; this change does not introduce a tagged usage shortcut. Ordinary pack selection, opt-in delegation, stdin, and native execution are unchanged.

Finite Linux comparisons use two actual SHA-1 packs and check object-store file contents, index, HEAD, config, working file, and root entries after setup. No pack deletion, optimizer completeness, cross-platform native parity, or complete command audit is claimed. All 430 audit scopes remain partial.
