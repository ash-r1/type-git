# Diff stat numeric callbacks

The four scalar options `--stat-width`, `--stat-name-width`, `--stat-graph-width`, and `--stat-count` use `diff.c:diff_opt_stat`. Git calls `strtoul` with base 10, rejects an unconsumed suffix, ignores `errno`, and stores the result in an `int`. Empty strings, signs, leading C whitespace, leading zeroes, and saturated unsigned-long overflow are accepted. Hexadecimal notation and trailing whitespace are rejected. This differs from the ordinary checked integer callback.

`--stat` uses a separate grammar: a bare option or up to three comma-separated decimal fields. Explicitly empty fields become zero; omitted fields retain their prior native value. The registered compound profile models acceptance only, with no ordering relation between fields. It does not predict rendering or replace native state handling. The scalar callback registration deliberately has no automatic function binding: the same C function handles both scalar and compound options, so the shared diff group binds each spelling explicitly.

The selected executable's established C-long width and unsigned negative-overflow capability are retained for scalar conversion as well as compound fields. Concrete command calls validate preserved literals; public argument aliases continue to describe shapes and admit dynamic strings. Invalid flag-union alternatives must not disappear during conditional-type distribution.

Help reachability is command-specific. The continuing `diff`, `diff-files`, `diff-index`, `diff-tree`, and `rev-list` parsers still reach callbacks after short help. Multiword full help is an invalid surrounding invocation for these commands. The native fixture measures an independent malformed diff option to distinguish usage exits of 129 and 255 without a version threshold.

The `diff --no-index`, `range-diff`, `diff-pairs`, `blame`, `annotate`, `pickaxe`, and `shortlog` loops reach preceding callbacks, then stop at help. Fifteen other scoped commands perform initial help handling before retained diff callbacks, even when those options precede help. `difftool` needs its own initial KEEP_UNKNOWN_OPT/KEEP_DASHDASH pass before invoking delegated diff. Internal `--help-all` follows these local help paths; a first `--help` on single-word commands keeps the documentation dispatch in `git.c`. Ignored tails retain their shape and NUL checks.

Pinned source evidence comes from Git 2.25.1 and 2.55.0 `diff.c`, `builtin/difftool.c`, the relevant initial-parser sources, and `parse-options.c`. Finite native matrices exercise all 27 scoped commands available in the selected Git. A missing builtin is skipped explicitly. Accepted invocations compare full status, stdout, and stderr against the same selected executable. Rejected callbacks require exact status 129 and their specific numerical or tuple diagnostic. Older selected Git 2.25/2.39 full `difftool` help can terminate with SIGSEGV while printing a hidden NULL option description in `parse-options.c`. An independent bare-full-help probe identifies this source behavior. These cases assert exact native status, streams, and signal propagation through the adapter; they are not successful native command executions. Unexpected signals in any other case remain failures. Every case preserves the fixture's file, index, HEAD, config, and directory entries.

These checks do not establish all configurations, abbreviations, later rendering limits, or every platform ABI. Validation records distinguish completed checks, failures, skips, and pending work against each actual head. All command audits remain partial.
